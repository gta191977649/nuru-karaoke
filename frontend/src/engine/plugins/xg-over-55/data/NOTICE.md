# midi-db data notice

`midiDb.generated.js` contains a minimized, transformed snapshot of data from
[ltgcgo/midi-db](https://github.com/ltgcgo/midi-db), pinned to commit
`4f1b262fede3e999519e7e334bb25b779b506379`.

The upstream data is licensed under
[Creative Commons Attribution-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-sa/4.0/).
The generated file retains that data license. Application source code outside
the generated data is not relicensed by this notice.

Changes made for this project: selected fields were parsed, normalized to
numeric MIDI addresses, sorted, and serialized as a JavaScript module.
